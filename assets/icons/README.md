# JPM interface icons

Original 24 × 24 SVG icons, designed in the project's Figma component library.
Use a 1.6px stroke with rounded caps and joins; color inherits from `currentColor`.
Company and technology brand marks remain in their existing collections.

Figma: https://www.figma.com/design/3djemfKOr6xUsQ8WaPs6gK?node-id=116-2

Use `i-jpm-<filename>` with Nuxt UI's icon components. The local collection is
registered in `nuxt.config.ts` and bundled for static/offline rendering.
